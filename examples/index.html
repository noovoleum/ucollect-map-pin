@noovoleum/map-pin

Pass props in and get pin artwork back, like an avatar component. The package only draws. Your app decides which state, banner and frame each station gets.

1 · Inline SVG

import { pinSvg } from '@noovoleum/map-pin';
el.innerHTML = pinSvg({ state: 'available', kind: 'station', size: 48 });

2 · Partner frames

pinSvg({ state: 'available', kind: 'station', size: 48,
         frame: { pattern: 'stripes', colors: ['#E31E24', '#FFD200'] } })

4 · MapLibre GL JS


The app maps the backend status to a pin state, picks the banner, and names each image after everything that changes its pixels. The package itself contains none of that logic.


const STATE = new Map([['active','available'],['available','available'],['closed','closed'],['planned','planned']]);
const toState = (status) => STATE.get(status) ?? 'maintenance';   // anything unknown means "doesn't work"
const key = (p, dpr) => ['pin', p.state, p.kind, p.banner ?? '-', p.frame?.pattern ?? '-',
                         (p.frame?.colors ?? []).join('.'), p.size, dpr].join('|');
